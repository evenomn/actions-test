### 【严重】Synology DSM OAuth参数注入
[CVE-2026-120382](https://nvd.nist.gov/vuln/detail/CVE-2026-120382) · CVSS 9.8 · P1 重点关注 · 披露 2026-11-23
类型: SQL注入(核心关注) | 利用条件: 远程·免认证,难度低
影响: Synology(产品与版本待 NVD/厂商补充),组件类别 NAS/存储
摘要: 远程攻击者可经DSM的OAuth API的参数拼接注入命令分隔符,读写任意文件并造成拒绝服务
复现价值: 一般 — 入口为DSM OAuth API参数,注入分隔符实现文件读写;暂无;影响面 NAS存储管理面,常暴露于互联网
处置建议: 升级到对应分支修复版(如7.2.2-72806-11),并限制DSM管理面暴露
原文: An improper neutralization of argument delimiters in a command vulnerability in the OAuth API in Synology DiskStation Manager (DSM) before 7.1.1-42962-10, 7.2.1…
资料: [NVD 详情](https://nvd.nist.gov/vuln/detail/CVE-2026-120382) · [参考](https://www.synology.com/en-global/security/advisory/Synology_SA_26_21)
